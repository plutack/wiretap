# wiretap v0.2.14

This release adds application-wide theme presets and broadens syntax highlighting while preserving Wiretap's bounded large-payload behavior.

## Application themes

The desktop Interface settings now include System, Wiretap Dark, Wiretap Light, Nord, Catppuccin Mocha, and Catppuccin Latte. Theme changes apply immediately to navigation, panels, forms, status states, the transform editor, and payload syntax.

Wiretap's component styles now use shared semantic design tokens, so the complete workbench follows the selected palette consistently. The preference stays local to the desktop alongside text size and row density.

## Bounded syntax highlighting

Supported small bodies can now highlight JSON, JavaScript, HTML/XML, CSS, YAML, TOML, and GraphQL. On compatible webviews, Microlighter uses CSS highlight ranges without producing a span for every token.

The existing safety limits remain: syntax formatting and highlighting apply only to complete bodies no larger than 100 KiB, while capture previews start at 256 KiB and expand progressively. Larger payloads render as bounded plain text.
