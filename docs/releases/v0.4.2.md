# wiretap v0.4.2

This release makes the desktop search controls easier to find, understand, and
use across window sizes.

## Body search is part of the query

The optional **Bodies** scope now lives inside the Traffic search field instead
of being separated from it by result metadata. It remains off by default and
continues to include bounded request and response body content only when you
choose it.

## Search controls are consistent

The search field now uses one Wiretap-styled clear button rather than depending
on the host webview's native search control. The button has a larger target,
stays visually aligned with the field, and returns focus to the query after it
clears the text. **Clear filters** in the command palette also clears the visible
query and the optional body scope, so the controls always match the results.

The toolbar also wraps cleanly in narrow windows, keeping the tabs, query, and
body-search scope usable without crowding or clipping.

## Keyboard shortcuts are visible

The command palette now has a visible top-bar entry showing `Ctrl K`, so the
shortcut is discoverable before someone already knows it. Search has its own
non-conflicting `/` shortcut, shown in the field when it is empty. Keyboard
focus stays inside the palette while it is open and returns to the invoking
control when it closes.
