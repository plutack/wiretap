## One local history, three interfaces

The desktop GUI, terminal UI, and CLI use the same local SQLite store. Choose the interface that fits the moment without splitting capture history.

Wiretap is meant to be self-hosted. Outbound interception stays on your machine, while public webhook ingress runs through your own `wiretap-relay` hosted deployment.
